# Real Life Application

High-order thinking skills (HOTS) plays an essential role in computer science and data engineering as this field requires people to be able to apply high-level thinking skills in solving problems, make decisions, innovate and strive to compete globally. Within the realm of computational thinking, critical thinking can truly assist people in designing efficient algorithms, debugging code as well as identifying creative and alternative solutions to solve complex problems. Furthermore, in the computer science field, it is essential to encourage creative thinking by combining programming and visual art skills in introductory computer science projects. In data engineering, HOTS are essential in analysing the data pipeline, evaluating alternative solutions in solving complex data problems as well as creating a creative and efficient data architecture. These skills enable data engineers to think critically, interpret data patterns and continuously improving the data systems so it meet the requirement.
